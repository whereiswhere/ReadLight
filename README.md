## Features

* Paginated reading with no screen touch distraction, you could rest fingers on text when reading
* Hardware scroll wheel for page turning
* Table of contents with nested chapter support
* Reading progress saved per book + finish read indicator.
* Footnote overlay — tap a footnote link to see its content without leaving the page
* Image overlay — large images are replaced with tappable text buttons to avoid breaking page layout
* Brightness control via scroll wheel when in the book list or table of contents

## Controls

| Input | In Reader | In Book List / TOC |
|---|---|---|
| Scroll Up Wheel | Next page | Increase brightness |
| Scroll Down Wheel | Previous page | Decrease brightness |
| Camera Focus | Toggle table of contents | — |
| Camera Focus + Shutter | Return to book list | — |

## Setup

1. Place `.epub` files in `/sdcard/Books/` on your Light Phone
2. Grant file access permission on first launch
3. Optionally grant "Modify system settings" permission for brightness control
